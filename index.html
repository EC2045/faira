01 — PHONOLOGY

音韻と表記

ファライ語はローマ字読みを基本とするが、いくつかの重要な例外と特殊規則がある。子音 c は常に黙字、ti では t が消音となる。

Ä

キカンホ（気管保）システム

ä ë ï ö ü の5母音は息を吸い込みながら発音する吸気音（キカンホ）。

目的語の末尾に必ずキカンホが付き、文中で「どこまでが目的語か」を耳で判別できる。c や ti が省略された際もその直後にキカンホが発生し、元の綴りを音声で復元できる。

※バイナリや歌では省略・不可聴となる場合あり

c

c の消音

c は常に発音しない。chi → 「ひ」、Cirku → 「イルク」

ti

ti の t 消音

ti の綴りのとき t が消える。直後の母音はキカンホになる。

ra

巻き舌 ra

ra となったとき、巻き舌の A として発音する。

aa

母音の長音化

母音が連続するとき長音として発音。Ta aga → 「ターガー」

03 — FAARAO SCRIPT

ファーラオ文字

ファライ語専用の表記体系。音節（最大3音）を1ブロックに収め、左上・右上・下の位置に配置する。目的語末尾のキカンホも視覚的に区別される。

プリセット
SCRIPT RULES

ブロック構成

1ブロック最大3音節。左上（A）→ 右上（D）→ 下中央（S）の順に配置。

キカンホ

ä ë ï ö ü はベース母音画像の上に ¨ をオーバーレイして吸気音を表現。

KU接近

K の直後に U が来るとき、U パーツを左にスライドして K に密着させる。

単語間スペース

スペースで単語を区切りワードラッパーで管理。文字幅は自動調整。
